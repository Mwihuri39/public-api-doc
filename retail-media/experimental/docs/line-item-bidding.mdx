## Overview

Use the Line Item Bidding Strategy endpoints to retrieve and update the bidding configuration of an Onsite Display Auction line item, including the active strategy and any preserved Adaptive or Standard settings.

<Info>
  **Availability: Available**

  This endpoint is available in the **Experimental** version of the Retail Media API only.
  Experimental endpoints may change without prior notice. See the [versioning policy](/criteo-apis/docs/versioning-policy) for details.
</Info>

## Endpoints

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/experimental/retail-media/line-items/{line-item-id}/bidding-strategy` | Retrieve the current bidding strategy configuration for a line item. |
| `POST` | `/experimental/retail-media/line-items/{line-item-id}/set-bidding-strategy` | Update the bidding strategy configuration for a line item. |

***

## Get Bidding Strategy

<EndpointBadge method="get">
```http
https://api.criteo.com/experimental/retail-media/line-items/{line-item-id}/bidding-strategy
```
</EndpointBadge>

### Path parameter

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `line-item-id` | string | Yes | Identifier of the Onsite Display Auction line item. |

The authenticated user must have permission to view the requested line item.

### Sample request

```bash
curl -X GET "https://api.criteo.com/experimental/retail-media/line-items/123456789012345678/bidding-strategy" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Accept: application/json"
```

### Response attributes

Attributes are nested under `data.attributes.cpm` in the response envelope.

| Attribute | Type | Description |
| --- | --- | --- |
| `bidStrategy` | string | The active bidding strategy for the line item. Either `Adaptive` or `Standard`. |
| `adaptiveBiddingSettings.maxBid` | number | The maximum bid the Adaptive strategy may use, in the line item's currency. |
| `standardBiddingSettings.auctionBids[].bid` | number | The bid amount for a page type, in the line item's currency. |
| `standardBiddingSettings.auctionBids[].pageType` | string | The page type this bid applies to. One of: `Search`, `Home`, `Browse`, `Checkout`, `Category`, `ProductDetail`, `Confirmation`, `Merchandising`, `Deals`, `Favorites`, `SearchBar`, `CategoryMenu`, `AiAssistant`. |

### Sample response

```json
{
  "data": {
    "type": "LineItemBiddingStrategyResponse",
    "attributes": {
      "cpm": {
        "bidStrategy": "Adaptive",
        "adaptiveBiddingSettings": {
          "maxBid": 2.8
        },
        "standardBiddingSettings": {
          "auctionBids": []
        }
      }
    }
  },
  "warnings": [],
  "errors": []
}
```

### Responses

| Status | Description |
| --- | --- |
| `200 OK` | Returns the current bidding strategy configuration for the line item. |
| `400 Bad Request` | The line item type is not supported. Only Onsite Display Auction line items are supported. |
| `401 Unauthorized` | The caller is not authenticated. |
| `403 Forbidden` | The caller does not have access to the requested line item. |
| `500 Internal Server Error` | The configuration could not be retrieved. Retry the request. If the failure persists, contact support. |

## Set Bidding Strategy

<EndpointBadge method="post">
```http
https://api.criteo.com/experimental/retail-media/line-items/{line-item-id}/set-bidding-strategy
```
</EndpointBadge>

### Path parameter

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `line-item-id` | string | Yes | Identifier of the Onsite Display Auction line item. |

The authenticated user must have permission to edit the requested line item. Omitted settings are preserved — only submitted fields are updated.

### Request attributes

Attributes are nested under `data.attributes.cpm` in the request envelope.

| Attribute | Type | Description |
| --- | --- | --- |
| `bidStrategy` | string | The active bidding strategy to set. Either `Adaptive` or `Standard`. |
| `adaptiveBiddingSettings.maxBid` | number | The maximum bid the Adaptive strategy may use, in the line item's currency. |
| `standardBiddingSettings.auctionBids[].bid` | number | The bid amount for a page type, in the line item's currency. Replaces all existing Standard bids. |
| `standardBiddingSettings.auctionBids[].pageType` | string | The page type this bid applies to. One of: `Search`, `Home`, `Browse`, `Checkout`, `Category`, `ProductDetail`, `Confirmation`, `Merchandising`, `Deals`, `Favorites`, `SearchBar`, `CategoryMenu`, `AiAssistant`. |

### Sample request

```bash
curl -X POST "https://api.criteo.com/experimental/retail-media/line-items/123456789012345678/set-bidding-strategy" \
  -H "Authorization: Bearer <MY_ACCESS_TOKEN>" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  --data-raw '{
    "data": {
      "type": "LineItemBiddingStrategyRequest",
      "attributes": {
        "cpm": {
          "bidStrategy": "Adaptive",
          "adaptiveBiddingSettings": {
            "maxBid": 4.2
          }
        }
      }
    }
  }'
```

### Response attributes

Same structure as [Get Bidding Strategy](#get-bidding-strategy) — returns the saved configuration after the update.

### Sample response

```json
{
  "data": {
    "type": "LineItemBiddingStrategyResponse",
    "attributes": {
      "cpm": {
        "bidStrategy": "Adaptive",
        "adaptiveBiddingSettings": {
          "maxBid": 4.2
        },
        "standardBiddingSettings": {
          "auctionBids": []
        }
      }
    }
  },
  "warnings": [],
  "errors": []
}
```

### Responses

| Status | Description |
| --- | --- |
| `200 OK` | Returns the saved bidding strategy configuration. Inspect `errors` and `warnings` before treating the response as complete. |
| `400 Bad Request` | The line item type is not supported, or the submitted configuration is invalid. Only Onsite Display Auction line items are supported. |
| `401 Unauthorized` | The caller is not authenticated. |
| `403 Forbidden` | The caller does not have access to the requested line item. |
| `500 Internal Server Error` | The configuration could not be saved. Retry the request. If the failure persists, contact support. |
