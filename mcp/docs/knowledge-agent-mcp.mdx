## Overview

The Knowledge Agent MCP is a second MCP server you add alongside your existing Criteo MCP connection. It grounds your agent's answers in approved Criteo product knowledge from the Criteo Help Centers and API Developer Portal.

Your Marketing Solutions MCP or Retail Media MCP stays the action and data layer. The Knowledge Agent MCP is the knowledge layer.

<Info>
  If you are integrated with more than one Criteo MCP, specify the `product` parameter in your prompt (e.g. "Commerce Max"). See [Product parameter](#product-parameter) below.
</Info>

***

## Add the endpoint

Register it as an additional MCP server alongside your existing Marketing Solutions MCP or Retail Media MCP — no separate credentials required.

```
https://mcp.criteo.com/criteo-knowledge/mcp
```

Refer to [Access Flows](/mcp/docs/access-flows) for the step-by-step setup on Claude, ChatGPT, or other platforms.

***

## Product parameter

Pass `product` in your prompt to direct the agent to the right knowledge base. This is recommended when you have more than one Criteo MCP connected.

| Value | Knowledge base |
| :---- | :------------- |
| `Growth` | Commerce Growth / Marketing Solutions |
| `Grid` | Commerce Grid |
| `Max` | Commerce Max / Retail Media |

`Growth` is the default if `product` is omitted.

To maintain context across a multi-turn conversation, pass the `session_id` returned in the first response back in subsequent calls. If omitted, each call starts a new session.

***

## What the Knowledge Agent does

- Grounds answers in approved Criteo product knowledge from the Criteo Help Centers and API Developer Portal
- Provides product explanations, how-to guidance, and interpretation your agent uses alongside marketing data and actions
- Your Marketing Solutions or Retail Media MCP stays the action and data layer
