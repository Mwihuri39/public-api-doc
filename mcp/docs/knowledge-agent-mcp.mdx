## Overview

The Knowledge Agent MCP is a second MCP server you add alongside your existing Criteo MCP connection. It grounds your agent's answers in approved Criteo product knowledge from the Criteo Support Center and API Developer Portal.

It does not replace your existing MCP — it complements it:

| Layer | Server | Role |
| :---- | :----- | :--- |
| Action / data | Your existing Criteo MCP | Creates campaigns, pulls reports, manages line items |
| Knowledge | Knowledge Agent MCP | Explains how things work, answers how-to questions, interprets results |

<Info>
  If you are connected to more than one Criteo MCP, specify the `product` parameter in your prompt so the agent uses the right knowledge base. See [Product parameter](#product-parameter) below.
</Info>

***

## Add the endpoint

You keep your existing authentication. The Knowledge Agent MCP registers as an additional server alongside your current Criteo MCP — no separate credentials are introduced.

**Knowledge Agent MCP endpoint:**

```
https://mcp.criteo.com/criteo-knowledge/mcp
```

Add it to your MCP client the same way you added your existing Criteo MCP connection. Refer to [Access Flows](/mcp/docs/access-flows) for the step-by-step process for Claude, ChatGPT, or other platforms.

***

## Product parameter

Pass `product` in your prompt to direct the agent to the right knowledge base. This is recommended when you have more than one Criteo MCP connected.

| Value | Knowledge base |
| :---- | :------------- |
| `Growth` | Commerce Growth / Marketing Solutions |
| `Grid` | Commerce Grid |
| `Max` | Commerce Max / Retail Media |

`Growth` is the default if `product` is omitted.

**Example prompt:**

> "Using product Max, explain how store targeting works for preferred line items."

***

## What the Knowledge Agent does

- Grounds answers in approved content from the Criteo Support Center and API Developer Portal
- Provides product explanations, how-to guidance, and interpretation your agent uses alongside marketing data and actions
- Stays read-only — all writes and data operations remain with your existing Criteo MCP
